Most of what I build is published under one of two organizations. Source for both
lives on [[https://gitbay.org][gitbay]].

* krz

[[https://krz.sh][krz]] builds native apps and self-hosted, privacy-respecting frontends. Local-first
data, few dependencies, no ads, no tracking. Source: [[https://gitbay.org/krz][gitbay.org/krz]].

** Apps

- [[https://krz.sh/apps/hutch/][Hutch]]: a native iOS client for SourceHut.
- [[https://krz.sh/apps/domain-dig/][Domain Dig]]: DNS, TLS, email security and ownership for any domain.
- [[https://krz.sh/apps/daybyday/][Day by Day]]: an educational iOS app with learning games for young children.
- [[https://krz.sh/apps/moonrise/][Moonrise]]: the sky tonight, the solar system, the Sun and launches.
- [[https://krz.sh/apps/orgstar/][orgstar]]: an Org mode editor and agenda for Mac, iPhone and iPad.
- [[https://krz.sh/apps/gitbay/][gitbay]]: a native iOS client for gitbay.

** Tools

- [[https://gitbay.org/krz/orgo][orgo]]: the org-mode static site generator that builds this site.
- [[https://gitbay.org/krz/nfogen][nfogen]]: generates scene-style NFO files.
- [[https://gitbay.org/krz/skunky-art][SkunkyArt]]: a privacy frontend for DeviantArt that works without JavaScript.

krz also hosts public frontends and tools: [[https://krz.sh/services/][krz.sh/services]].

* Audit Labs

[[https://audit-labs.dev][Audit Labs]] makes open-source tools for audit evidence: collect it from real systems,
seal it tamper-evident, map it to SOC 2, ISO 27001 and NIST controls, and measure how
much of a framework it covers. The tools are written for auditors. Source:
[[https://gitbay.org/audit-labs][gitbay.org/audit-labs]].

- [[https://gitbay.org/audit-labs/audit-tools][audit-tools]]: scripts that collect evidence from cloud platforms, GitHub, databases
  and operating systems.
- [[https://gitbay.org/audit-labs/evidence-seal][evidence-seal]]: tamper-evident seals and chain of custody for evidence packages.
- [[https://gitbay.org/audit-labs/audit-report][audit-report]]: turns evidence into control-mapped reports.
- [[https://gitbay.org/audit-labs/control-coverage][control-coverage]]: scores evidence against a framework's full control catalog.
- [[https://gitbay.org/audit-labs/gh-attest][gh-attest]]: a self-hosted GitHub App that records security settings as evidence.

The [[https://audit-labs.dev/walkthrough/][walkthrough]] runs the whole chain end to end.
